# Launch kit

This directory turns the verified v0.1.0 evidence into honest, channel-specific launch material. It
adapts the useful parts of the user-provided [Catime growth retrospective](https://vladelaina.com/blog-post?slug=Catime_growth_notes): ship a useful prototype, make the README bilingual and visual, show a short real demo, submit to relevant communities, and write personal outreach.

Nothing here should be posted before the tagged release, green CI/security checks, and clean-install
smoke test are public. Do not buy stars, exchange stars, mass-DM strangers, automate comments, or imply
adoption that has not happened.

Suggested sequence:

1. GitHub Release and one concise personal post.
2. HelloGitHub submission with the Chinese quick start.
3. LINUX DO technical build log focused on privacy tradeoffs and deterministic rules.
4. Appinn submission only if the editors consider a developer CLI in scope.
5. One-to-one outreach to maintainers who publicly discuss data contracts or schema drift.
6. Respond to issues, improve onboarding, and let stars follow utility.

Use [posts.md](posts.md), [outreach.md](outreach.md), and
[demo-video-script.md](demo-video-script.md) as drafts. Personalize every message and verify each
community's current rules immediately before posting.
